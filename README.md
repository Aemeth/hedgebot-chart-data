# Данные графика расходов на хеджирование ETH

Проверенные данные для hedgebot.io и расчёта ожидаемых расходов на хеджирование. Два направления: CALL — хедж при росте цены; PUT — хедж при падении цены. Расходы приведены к году; меньше — дешевле. Премия опциона в эти расходы не входит.

- [latest.json](latest.json) — постоянная точка входа.
- [AI_INTEGRATION.md](AI_INTEGRATION.md) — контракт загрузки, единиц и отображения.
- [DESCRIPTION_RU.md](DESCRIPTION_RU.md) — описание для посетителей.

Выпуск `2026-10-04-v2`: 18 доступных недель с экспирациями 29.05–02.10.2026, одиннадцать расстояний $5, $10, $12.5, $15, $20, $25, $35, $45, $55, $65, $75; 22 средних и 396 недельных сценариев. Неделя 07.08.2026 исключена из-за недостаточной исходной истории. Семь более ранних недель шестимесячного окна не включены из-за отсутствия исходных данных на пятничном якоре. Расстояния и стороны используют одни и те же 18 недель.

Каждый выпуск содержит `chart.json`, `chart.csv` и `manifest.json` с размерами и SHA-256. Схема данных 1.0.0 сохранена. Число точек и диапазон читаются из выпуска и не должны быть зафиксированы в коде потребителя.

Обновления планируются по субботам после проверки новой завершённой недели. Настройки заново выбираются по всем принятым полным неделям шестимесячного календарного окна. Недоступные недели остаются явно отмеченными, поэтому текущая выборка не является полным шестимесячным набором. Старые выпуски сохраняются; указатель меняется атомарно после проверки. При задержке остаётся предыдущий проверенный выпуск с его фактическими датами.

В выпуске `2026-10-04-v2` добавлены доступные недели 29.05 и 02.10.2026; средние расходы и описательная статистика пересчитаны по принятым настройкам. Линии рассчитаны как `a + b*ln(x)`, где `x` — расстояние в USD. Сайт и бот используют опубликованные координаты `series[].trend` внутри диапазона $5–75.
