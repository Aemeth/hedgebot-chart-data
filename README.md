# Данные графика расходов на хеджирование ETH

Готовые данные и описания для графика зависимости расходов на хеджирование от удаления от страйка. Два направления: CALL — хедж при росте цены; PUT — хедж при падении цены. Расходы приведены к году для сравнения; меньше — дешевле.

- [latest.json](latest.json) — постоянная точка входа, указывает на проверенный выпуск.
- [Инструкция для ИИ разработчика](AI_INTEGRATION.md) — загрузка, отображение и проверка графика.
- [Описание для посетителей](DESCRIPTION_RU.md) — факторы, выборка и понятные пояснения.

Выпуск `2026-09-13-v2` содержит 14 недель с датами завершения от 29 мая до 4 сентября 2026 года, 8 расстояний от $10 до $45, 16 средних значений и 224 недельных сценария. Это 14 периодов истории; направления и расстояния используют те же недели. Неделя 7 августа исключена из-за недостаточной исходной истории. Полный состав указан в `sample`.

В каталоге выпуска: `chart.json` — данные и готовые пояснения, `chart.csv` — 16 средних со статистикой, `manifest.json` — размеры файлов и контрольные суммы SHA-256. Дата выпуска и дата последней недели — разные сведения.

Новые проверенные выпуски планируются по субботам. Окно расчёта — последние четыре календарных месяца полностью завершённых недель. Старые выпуски сохраняются для воспроизводимости; `latest.json` обновляется после проверки нового выпуска. При задержке расчёта сохраняется предыдущий выпуск с его фактическими датами.
