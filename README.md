# Данные графика расходов на хеджирование ETH

Проверенные данные для hedgebot.io и расчёта ожидаемых расходов на хеджирование. Два направления: CALL — хедж при росте цены; PUT — хедж при падении цены. Расходы приведены к году; меньше — дешевле. Премия опциона в эти расходы не входит.

- [latest.json](latest.json) — постоянная точка входа.
- [AI_INTEGRATION.md](AI_INTEGRATION.md) — контракт загрузки, единиц и отображения.
- [DESCRIPTION_RU.md](DESCRIPTION_RU.md) — описание для посетителей.

Выпуск `2026-10-04-v1`: 16 недель с экспирациями 05.06–25.09.2026, одиннадцать расстояний $5, $10, $12.5, $15, $20, $25, $35, $45, $55, $65, $75; 22 средних и 352 недельных сценария. Неделя 07.08.2026 исключена из-за недостаточной исходной истории. Расстояния и стороны используют одни и те же 16 недель.

Каждый выпуск содержит `chart.json`, `chart.csv` и `manifest.json` с размерами и SHA-256. Схема данных 1.0.0 сохранена. Число точек и диапазон читаются из выпуска и не должны быть зафиксированы в коде потребителя.

Обновления планируются по субботам после проверки новой завершённой недели. Настройки заново выбираются по всем принятым неделям текущего окна: последние четыре календарных месяца полностью завершённых недель. Старые выпуски сохраняются; указатель меняется атомарно после проверки. При задержке остаётся предыдущий проверенный выпуск с его фактическими датами.

В выпуске `2026-10-04-v1` добавлены проверенные расстояния $12.5 и $65; средние расходы и описательная статистика пересчитаны по принятым настройкам. Новые недели в этом выпуске не добавлялись. Линии рассчитаны как `a + b*ln(x)`, где `x` — расстояние в USD. Сайт и бот используют опубликованные координаты `series[].trend` внутри диапазона $5–75.
